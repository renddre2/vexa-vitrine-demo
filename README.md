# Demonstração de vitrine — Confeitaria

Exemplo totalmente fictício para mostrar a um comércio interessado o funcionamento de uma vitrine digital. Nome, preços, produtos e horários são ilustrativos. **Nenhum pedido é enviado**: `config.js` tem `whatsapp: ""`.

Para abrir, inicie um servidor estático a partir da raiz do projeto com `python -m http.server 4173` e acesse `http://localhost:4173/demonstracoes/confeitaria/`.

É uma cópia autocontida da vitrine genérica (`index.html`, `estilos.css`, `app.js`, `pedido.js`, `config.js`). Pode ser adaptada separadamente a cada cliente, mediante autorização para uso dos dados e da marca. Edite `config.js` com produtos e preços confirmados, substitua os textos de demonstração e valide carrinho, mensagem e visual no celular antes de qualquer publicação. O valor de implantação e limites do serviço constam em `VENDER.md` na raiz.

Não utilizar a marca ou as fotos de potenciais clientes sem permissão. Não configurar o WhatsApp real de um negócio antes de confirmar o número e autorização.
